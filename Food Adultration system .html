01 / PROBLEM STATEMENT

Food Quality Assessment

Food quality assessment can involve inspection of products using visual characteristics, chemical composition and other measurable parameters.

The research investigated how artificial intelligence and machine learning could support automated food-quality detection.

The work focused on fruits and dairy products and included dataset collection, preprocessing, feature identification, model development, testing and validation.

05 / EXPERIMENT 01

Fruit Classification

A fruit image dataset was created using photographs collected from different vendors.

A convolutional neural network (CNN) was developed by training the dataset containing images of different fruits.

A graphical user interface was also designed for the fruit classifier, allowing an input image to be processed and an output to be displayed.
